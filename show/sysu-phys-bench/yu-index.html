Yu Index：基于绩点与教学班排名的课程给分水平指标

余荫铠 · SYSU-Phys-Bench

1. 定义

不同课程的原始绩点同时混合了个人表现与课程评分尺度，直接比较 GPA 难以单独刻画课程给分水平[2][3][5]。Yu Index 使用个人绩点和教学班排名分离这两个部分。

Y=G−13 Φ−1 ( n−r+58 n+14 )

其中，Y 为 Yu Index，G 为个人绩点，r 为教学班名次（第 1 名为最高），n 为教学班人数，Φ−1 为标准正态分布的逆累积分布函数。

Yu Index 与 GPA 使用相同的数值尺度。例如，Y = 4.20 表示根据该学生的绩点与名次推测，这门课程的教学班平均绩点约为 4.20。Yu Index 越高，课程整体给分越高；Yu Index 越低，课程整体给分越低。

2. 从个人绩点反推课程均值

设一门课程的教学班绩点近似服从均值为 μ、标准差为 σ 的正态分布：

Gclass∼N(μ,σ2)

一个学生的绩点可以写成：

G=μ+σz

z 表示该学生在教学班成绩分布中的相对位置。由此可直接反解课程平均绩点：

μ^=G−σz

因此，Yu Index 不是把绩点与排名任意加权，而是在估计一个与 GPA 同尺度的量：课程的教学班平均绩点。

3. 将教学班排名转换为正态位置

教学班共有 n 人时，第 r 名从低到高对应第 n − r + 1 个观测。采用 Blom 正态顺序统计量位置，将名次转换为累积概率[1]：

p= n−r+58 n+14

再用 z = Φ−1(p) 得到该名次通常对应的标准差位置。该转换体现了排名的非线性：班级中部的若干名次差异较小，而第一名、第二名等极端名次对应更明显的相对表现差异；不同规模教学班中的相同名次也会得到不同的 z 值。

4. 典型班内绩点标准差

每门课程只有一个人的绩点与排名，不能同时估计该课程的均值和标准差。SYSU-Phys-Bench 因此为所有课程使用统一的典型班内绩点标准差 σ0。

对成绩单中 63 条同时具有绩点与教学班排名的课程记录，先由排名计算正态位置 zj，再拟合：

Gj=a+σ0zj+εj

拟合得到 σ0 ≈ 0.341。公开定义取与该估计接近且形式简洁的 σ0 = 1/3，从而得到最终公式。

5. 数据校验

在这 63 条课程记录中，Yu Index 与教学班名次占比的皮尔逊相关系数约为 −0.0004，与个人绩点的相关系数约为 0.840。前者表明 Yu Index 并不是教学班排名的线性复述，后者表明该指标仍然保留了绝对成绩信息。

变量关系皮尔逊相关系数
Yu Index 与教学班名次占比−0.0004
Yu Index 与个人绩点0.840

Yu Index 使用排名估计个人相对表现，再从绩点中扣除这一部分，以获得课程给分水平的估计值。

6. 多样本课程级估计

同一课程收集到多位贡献者或多个学期的有效记录后，先分别计算每条记录的 Yu Index。设课程 c 在当前筛选范围内共有 mc 条记录，则课程级 Yu Index 定义为：

Y¯c = 1mc ∑i=1mc Yi

每条观测在课程级平均中权重相同。网页同时报告样本数与独立贡献者数量；类别、学年和学期筛选先作用于观测记录，再计算当前视图的课程汇总值。随着独立样本增加，单个学生相对表现带来的随机误差会在课程级平均中减小。

7. 计算示例

“热力学与统计物理”的个人绩点为 3.8，教学班排名为 2/43。由 Blom 位置得到 p ≈ 0.9624，进而得到 z ≈ 1.7796：

Y=3.8−13×1.7796≈3.21

个人绩点为 3.8，但该成绩已经对应教学班第 2 名；模型将其中一部分解释为个人相对表现，估计课程平均绩点约为 3.21。

课程个人绩点教学班排名Yu Index
热力学与统计物理3.82/433.21
体育4.89/354.57

8. 指标意义

Yu Index 将“绝对绩点”和“班内相对表现”分开：排名越靠前，个人绩点中被解释为相对表现的部分越多；排名越靠后却仍取得较高绩点，模型反推出的课程平均绩点越高。

它回答的问题是“根据这份个人成绩与教学班名次，这门课程的整体给分大约处于什么水平”。不同课程的 Yu Index 可以直接按 GPA 尺度比较，也更适合比较明显的给分区间差异。

9. 方法关系

教育测量研究长期关注原始 GPA 混合学生表现、课程选择与评分尺度的问题。Adjusted GPA[2]、Achievement Index[3]、Grade Lift[4] 与 calibrated GPA[5] 等方法都试图分离学生水平和课程给分差异。Yu Index 面向只有绩点与教学班排名的单条观测，以正态顺序统计量提供的相对位置信息完成课程平均绩点估计，并可通过多条独立观测形成课程级汇总。
