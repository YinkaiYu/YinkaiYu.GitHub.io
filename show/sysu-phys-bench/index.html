Yu Index

Yu Index 是 SYSU-Phys-Bench 的课程级综合指标，用于同时表示课程绩点与教学班相对名次。

Yu Index = 100 绩点5 · 教学班名次教学班人数

该指标等于“绩点得分率”与“教学班名次占比”的几何平均数乘以 100，取值范围为 0—100。绩点相同时，教学班名次越靠后，Yu Index 越高；教学班名次占比相同时，绩点越高，Yu Index 越高。因此，较高的 Yu Index 对应“排名较低、绩点较高”的组合，较低的 Yu Index 对应“排名较高、绩点较低”的组合。
