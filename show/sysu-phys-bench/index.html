Yu Index

Yu Index 是 SYSU-Phys-Bench 的课程给分友好度指标。

Y = G − 13 Φ−1 ( n−r+58 n+14 )

其中，G 为个人绩点，r 为教学班名次，n 为教学班人数，Φ−1 为标准正态分布的逆累积分布函数。Yu Index 越高，说明这门课程给分越友好。
